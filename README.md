# AI Agent Project 1: Foundations

## Project Overview

This project is part of the 90-day AI Agent Developer curriculum. It focuses on establishing foundational knowledge of LLMs, backend development, and building production-ready AI agents.

## Setup Instructions

1. Clone this repository
2. Create virtual environment: `python3 -m venv .venv`
3. Activate virtual environment: `source .venv/bin/activate` (macOS/Linux) or `.venv\Scripts\activate` (Windows)
4. Install dependencies: `pip install -r requirements.txt`
5. Copy `.env.example` to `.env` and add your API keys
6. Run Day 1 API: `cd day_01 && uvicorn main:app --reload`

## Project Structure

- `day_01/`: Day 1 implementation (Development environment setup and REST API)
- `day_02/`: Day 2 implementation (Terminal mastery and automation)
- ...
